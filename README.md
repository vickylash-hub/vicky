# Vicky Lashenko — personal brand site

Vite + React site for [vickylashenko.com](https://vickylashenko.com).

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173/

## Build

```bash
npm run build
npm run preview
```

## Notes

- Contact email placeholder: edit `CONTACT_EMAIL` in `src/App.jsx`
- Testimonials: `src/data/testimonials.js` (sourced from Wayback Machine About page, Dec 2019)
